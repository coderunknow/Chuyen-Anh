# Security Policy

## Supported versions

This project is maintained as a learning/resource repository and is updated as needed.

## Reporting a vulnerability

Please report security issues privately via GitHub's security advisory workflow or by contacting the repository owner directly.

Do not open public issues for vulnerabilities or sensitive security findings.

## Safe use guidance

- Do not commit secrets, API keys, or personal data.
- Validate downloaded source material before republishing.
- Treat exam content and uploaded files as educational references, not authoritative official government releases.
